# Agent rows are flat, full-width, and fully clickable

Decided: 2026-10-18
Status: accepted

An agent's header row (Orchestrator or Claude Code) has no corner radius.
Unselected rows are transparent; the selected row fills with `Ledger.selected`.
The whole row selects the agent, not just its name; the chevron alone folds it.
Collapsed groups sit with no gap between them; an open group's content gets a small inset (6 pt above, 4 pt below).
