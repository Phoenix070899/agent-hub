# Keys for the Files column

Decided: 2026-10-19
Status: accepted

Supersedes: ui-ux/0008's list of taken shortcuts, which this extends; its rules still hold.
Shortcuts taken now: ⌘K Quick Open, ⌘N New Orchestrator, ⇧⌘N New Terminal, ⌥⌘N Fan Out a Task, ⌘0 first agent, ⌘L ledger, ⌘1 to ⌘9 repos, ⇧⌘[ and ⇧⌘] previous and next repo, ⌘D and ⇧⌘D split, ⌘W close pane, ⌥⌘D Changes, ⇧⌘Return send a review, ⇧⌘E Files, ⌘O Open in Editor, ⇧⌘R Reveal in Finder, ⌥⌘C Copy Path.
⇧⌘E shows the Files column and gives it the keyboard; pressed while the column shows but the keyboard is elsewhere, it gives it the keyboard; pressed in the column, it hides it and the terminal takes the keyboard back.
In the tree: ↑ ↓ move, → ← open and close folders, Space previews, Return types the file's `@path` into the terminal, Esc closes the preview, and typing a name jumps to it as in Finder.
⌘O, ⇧⌘R and ⌥⌘C act on the previewed file, else the tree's cursor.
The selected checkout's files also show in Quick Open, after commands, repos, agents and Workers.
