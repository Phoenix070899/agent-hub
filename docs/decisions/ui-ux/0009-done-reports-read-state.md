# Done reads like a mail inbox

Decided: 2026-10-18
Status: accepted

A Final Report the human has not opened shows a dot and a semibold title; opening it marks it read.
Rows offer Mark as Read or Unread and Dismiss in their context menu; the Done header shows "N unread" and "Clear read".
A report counts as read only when it settles while on screen or the human opens it, so Mark as Unread is never undone by a refresh.
