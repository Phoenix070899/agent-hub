# The Final Report fills the panel and reads as a large-type Markdown document

Decided: 2026-10-19
Status: accepted

The Final Report runs the full width of the panel inside 40 pt side margins, like rendered Markdown (ui-ux/0020); the 680 pt column left wide windows half empty.
Its title is 30 pt bold, each section heading (State, Changed, Verified) is 19 pt semibold over a rule, and body text is 15 pt with 7 pt between wrapped lines.
Each section's text renders as Markdown with the file preview's block renderer, so the bullets, `code`, and emphasis Workers write read as written instead of as raw marks.
