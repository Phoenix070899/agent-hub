# Echo Remote on the phone: Needs first, then repos, agents, and a screen with keys

Decided: 2026-10-24
Status: accepted

The home page is every repo's Needs you, oldest first, as cards with Echo's headline, the repo and agent, and Approve, Deny, Open or a reply field; then the repos, each with its Needs count.
A repo page lists its Needs, then each agent with its Workers under it, a Worker showing its state chip and its progress line or Final Report's first line; New starts an Orchestrator or Claude Code session with an optional request, name, and branch.
An agent's or Worker's page shows its screen as coloured text, read once a second while shown, a message box, and the keys Esc ↑ ↓ ⏎ Tab ⇧Tab ⌃C; Aa sets text size and line wrapping, which is on by default; a line drawn only of box rules shows as one thin rule.
A field being typed in is never redrawn under the thumb: the page waits for it to lose focus.
The screen is never resized from the phone, since that would resize the human's terminal on the Mac.
Echo's Settings gain a Remote section: the switch, one status line, the pairing QR code with Copy Link and New Pairing Link, and a link to get Tailscale while it is missing.
Colours are Echo's (paper, ink, the yellow marker), light and dark.
