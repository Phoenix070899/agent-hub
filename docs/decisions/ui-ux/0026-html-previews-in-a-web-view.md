# HTML files preview in a web view

Decided: 2026-10-21
Status: accepted

A `.html` or `.htm` file previews as the page, drawn by a web view that can read the whole checkout, so its styles, scripts, and images load; a Rendered and Source switch, as for Markdown, shows the coloured source instead.
The page loads again when the file changes on disk; a link to another site opens in the default browser, not in the tab.
The header adds "Open in browser", which hands the file to macOS's default app for it.
