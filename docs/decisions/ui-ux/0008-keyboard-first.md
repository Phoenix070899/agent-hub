# Every action has a keyboard path

Decided: 2026-10-19
Status: accepted

Each feature ships with a shortcut or a Quick Open command, and lists of lines or rows move with ↑ and ↓ and act on Return.
Shortcuts taken: ⌘K Quick Open, ⌘N New Orchestrator, ⇧⌘N New Terminal, ⌥⌘N Fan Out a Task, ⌘0 first agent, ⌘L ledger, ⌘1 to ⌘9 repos, ⇧⌘[ and ⇧⌘] previous and next repo, ⌘D and ⇧⌘D split, ⌘W close pane, ⌥⌘D Changes, ⇧⌘Return send a review.
Check this list before taking a new shortcut, and supersede this file when the list changes.
Key handlers on a container must ignore keys while a text field inside it is being edited.
