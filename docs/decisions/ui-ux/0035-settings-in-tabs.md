# Settings is one tab per feature

Decided: 2026-10-24
Status: accepted

Echo's Settings window is a toolbar of tabs, each with an icon: Window, Theme, Background, Font, Multiplexer, and Remote; the window takes each tab's height.
Theme holds the preset, its colours, the palette, and Match Orca; Background is the terminal background image.
A tab's page has no heading of its own, as the tab and the window title already name it.
Why: one long list had grown past a screen once Remote joined it, and the human asked for a tab per feature.
