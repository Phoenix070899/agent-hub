# Copy is plain, short, and uses the domain words

Decided: 2026-10-18
Status: accepted

Labels and messages use the words in `CONTEXT.md` (Orchestrator, Worker, Task, Final Report, Hub Session) and avoid the listed synonyms.
Sentence case for text in views; title case only for macOS menu items.
Meta strings are joined with commas, like "Orchestrator, opus"; no middle dots.
Only the plain hyphen "-" is used as a dash; the em dash is never used.
Errors say what happened and how to fix it, without apologising.
